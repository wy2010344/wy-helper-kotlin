# 07 多平台

引擎把平台差异收敛在少数几个 `expect` 声明上，通用逻辑全部在 `commonMain`。目前 **JVM / Desktop 可用**（`skia-engine/src/jvmMain`）。

## expect/actual 一览

| 声明 | 作用 |
|---|---|
| `PlatformCanvas` | 画布：矩形/圆角/椭圆/线/图像/段落 + 变换/裁剪/透明度 |
| `buildParagraph(spans, maxWidth, ...)` → `PlatformParagraph` | 文本排版（Skia Paragraph） |
| `PlatformImage` + `decodeImage(bytes)` | 位图与解码 |
| `clipboardGetText()` / `clipboardSetText(text)` | 剪贴板 |
| `KeyCode` | 键盘码枚举 |

对应 Desktop 实际实现（`skia-engine/src/jvmMain/kotlin/org/wy/engine/`）：

```
Platform.desktop.kt           // PlatformCanvas：Skia Canvas 封装
PlatformParagraph.desktop.kt  // FontCollection + ParagraphBuilder
PlatformImage.desktop.kt      // org.jetbrains.skia.Image
Clipboard.desktop.kt          // java.awt.Toolkit 剪贴板
KeyCode.jvm.kt                // AWT keyCode → KeyCode
```

## 事件桥接

平台层把 AWT/Swing 事件翻译成 `Renderer` 的公开方法（参考 `SkiaWindow.desktop.kt`）：

```kotlin
skiaLayer.addMouseListener(object : MouseAdapter() {
    override fun mousePressed(e: MouseEvent?)  { app.mouseDown(e.x.toFloat(), e.y.toFloat()) }
    override fun mouseReleased(e: MouseEvent?) { app.mouseUp(...) }
    override fun mouseClicked(e: MouseEvent?)  { app.mouseClick(...) }
})
// mouseMoved / mouseDragged → app.mouseMove(x, y)
// mouseWheel                       → app.mouseWheel(x, y, delta)
// keyPressed/keyTyped              → app.keyPress(char, code, ctrl, shift, alt, meta)
// 输入法组合                        → app.composingText(text, cursor)
```

## 接入新平台

1. 在 `skia-engine` 新建对应源集（如 `iosMain`），实现上面 5 组 `expect`
2. 把平台事件桥接到 `Renderer` 的公开入口（`mouseDown / mouseUp / mouseClick / mouseMove / mouseWheel / keyPress / composingText`）
3. 需要原生输入法时：实现 `setInputOverlayHandler(show, hide)`，让系统输入控件出现在指定屏幕坐标

## 无头渲染（测试用）

不依赖窗口也能验证渲染：用 Skia 离屏 Surface 构造 `PlatformCanvas` 再调 `render`：

```kotlin
val surface = Surface.makeRasterN32Premul(w, h)
app.render(PlatformCanvas(surface.canvas))   // app 是 Renderer 子类
```
