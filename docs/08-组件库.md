# 08 组件库（helper）

`org.wy.engine.helper` 下是可复用的标准组件。设计原则：**交互行为内置、符合标准；样式完全外置、可最大程度自定义**。

## 设计原则

每个组件拆成两层：

- **交互基类**（如 `ButtonBase`）：固定标准行为——点击 / 键盘触发、hover / pressed / focused 状态、disabled 语义、焦点环时机。业务不可绕过，保证所有组件交互一致。
- **视觉覆盖点**（`drawContent` / `drawFocusRing` / `argChildren` 等 open 方法）：样式 100% 自定义，默认样式只作参考。

默认样式统一从 [Theme] 读取 token（颜色 / 圆角 / 字号），不写死颜色值。两种自定义粒度：

1. **全局换肤**：替换 `Theme.current`，所有组件默认样式生效；
2. **局部定制**：`object : ButtonBase(this) { ... }` 覆盖视觉方法。

## Theme

`helper/Theme.kt` 提供样式 token（`ThemeColors` / `ThemeRadius` / `ThemeTextSize`），组件默认样式一律读它。选中态背景用 `primarySoft`（navItem 激活高亮等），hover 描边用 `borderHover`（输入框 / 滑杆悬停）：

```kotlin
// 全局换肤（启动时替换一次即可）
Theme.current = Theme(
    colors = ThemeColors.light().copy(primary = rgba(220, 38, 38))
)

// 局部定制：某个按钮不用主题，自己画
object : ButtonBase(this) {
    override fun drawContent(canvas: PlatformCanvas) {
        fillOuterRoundRect(canvas, 4f, if (pressed) darkRed else red)
    }
}
```

## 标准交互清单

组件基类内置的行为（对齐 web ARIA / Compose Material 交互基线）：

| 交互 | 行为 |
|---|---|
| 点击 | 指针 Click（Renderer 已按 5px / 500ms 判定）触发 |
| 键盘 | Enter / Space 触发（需持有焦点）；Slider 额外支持 Left / Right 步进 |
| 焦点 | `focusable` 进入 Tab 序；聚焦时绘制焦点环（画法由样式层决定） |
| disabled | 不进 Tab 序、不响应点击与键盘、无 hover / pressed 状态 |
| hover | 鼠标悬停生效；**触摸 / 笔设备不产生 hover**（避免 sticky hover），按下反馈仍保留 |
| pressed | 按下即时反馈（响应式信号，样式层读取） |

触摸 hover 依赖全局信号 `engineGlobal.lastPointerDevice`（见 [06](06-事件与焦点.md)）：平台通过 `mouseDown / mouseMove / mouseUp` 上报设备类型，组件据此抑制桌面式 hover。

## Button

交互基类 `ButtonBase` + 默认样式工厂 `button()`：

```kotlin
// 默认样式（读 Theme）：
button({ "保存" }, { save() }, variant = ButtonVariant.Primary, focusOrder = 1)
button({ "取消" }, { cancel() }, variant = ButtonVariant.Secondary, width = 70f)

// 完全自定义样式：继承基类，只画自己的：
object : ButtonBase(this) {
    override val argWidth: LayoutSize get() = LayoutSize(120f, false)
    override val argHeight: LayoutSize get() = LayoutSize(36f, false)
    override fun drawContent(canvas: PlatformCanvas) {
        // 可读取 hovered / pressed / isFocused 状态信号
        fillOuterRoundRect(canvas, 12f, if (pressed) ACCENT_DARK else ACCENT)
    }
}
```

`ButtonBase` 上可覆盖的视觉点：`drawContent`（背景 / 边框）、`drawFocusRing`（焦点环）、`argChildren`（内容，通常放文字或图标）、`argWidth` / `argHeight` / padding。

## 文本

`helper/Text.kt` 的 `text()`：宽度自适应内容的单行文本，组件 label 常用：

```kotlin
text({ "未保存" }, color = Theme.current.colors.textSecondary)
```

需要换行 / 省略 / 对齐时直接用 `WrappedTextNode`。

## TextField

`helper/TextField.kt` 的 `textField()`：单行输入框。光标 / 选区 / IME / 撤销重做等交互由 `EditableTextNode` 内置，工厂只提供默认视觉（背景 + 边框：聚焦主色描边、悬停描边、其余常规描边）与尺寸：

```kotlin
textField(
    value = { state.value },
    onChange = { state.value = it },
    focusOrder = 20,
    width = 240f, height = 34f,
)
```

值采用闭包读写（`value` / `onChange`），对接任意状态容器；需要更深定制时直接继承 `EditableTextNode`。

## Switch

`helper/Switch.kt`：交互基类 `SwitchBase` + 默认样式工厂 `switch()`。

`SwitchBase` 复用 `ButtonBase` 的点击 / Enter / Space / disabled / hover / pressed，只增加"开关状态 + 切换"语义：

```kotlin
switch({ notify.value }, { notify.value = it }, focusOrder = 22)
```

样式可自定义（override `drawContent` 画轨道 / 滑块、`drawFocusRing` 画焦点环）。

## Slider

`helper/Slider.kt`：交互基类 `SliderBase` + 默认样式工厂 `slider()`。

`SliderBase` 内置交互（值域 0..1）：指针按下即取值、拖动持续更新、聚焦时 Left / Right 步进 ±0.05、disabled 忽略一切：

```kotlin
slider({ fontSize.value }, { fontSize.value = it }, focusOrder = 25, width = 220f)
```

样式可自定义：`drawTrack` / `drawThumb` / `drawFocusRing` / `drawHoverRing`。

## SegTabs

`helper/SegTabs.kt` 的 `segTabs()`：分段控件（轨道背景 + 等宽分段）。每个分段复用 `ButtonBase` 交互，选中段显示 surface 卡片 + 主色文字：

```kotlin
segTabs(
    { active.value },
    { active.value = it },
    listOf(DemoTab.OVERVIEW to "概览", DemoTab.NOTES to "笔记"),
    focusOrderOffset = 10,  // 分段 focusOrder = offset + 下标；传 null 则按文档序
)
```

## NavItem

`helper/NavItem.kt` 的 `navItem()`：侧栏导航项，复用 `ButtonBase` 交互，视觉含激活态高亮（`primarySoft` 背景 + 左侧主色竖条）、可选图标圆点与角标：

```kotlin
navItem(
    label = { "设置" },
    active = { active.value == DemoTab.SETTINGS },
    onClick = { active.value = DemoTab.SETTINGS },
    focusOrder = 3,
    iconColor = AMBER,
    badge = { 3 },
)
```

## 浮层体系（Overlay）

`OverlayBase`（`helper/Overlay.kt`）是所有浮层（Dialog / Dropdown / Toast）的共享基类：作为渲染树中最后声明的子节点铺满窗口，打开 / 关闭由业务闭包驱动，**关闭时整个节点隐藏、不拦截任何事件**。

通用交互（内置）：

- **hide 跟随打开状态**：`isOpen()` 返回 false 时整层不可见，不占命中测试；
- **打开聚焦 / 关闭还原**：打开时自动聚焦内容里第一个可聚焦元素，关闭时把焦点还原给打开前的持有者；
- **Esc 关闭**：仅当焦点在本浮层内时响应（最上层打开者生效，天然支持嵌套）；
- **点击外部关闭**：点击浮层空白处触发 `onDismiss()`，内容节点需自行拦截冒泡（见各组件）；
- **焦点圈定**：`trapsFocus` 为 true（Dialog）时声明 `Node.focusTrap`，Tab / Shift+Tab 只在浮层内循环，焦点不逃逸。

三种浮层，同一模式（交互内置、样式外置）：

| 浮层 | 基类 / 工厂 | 特点 |
|---|---|---|
| 模态对话框 | `DialogBase` / `dialog()` | 圈定焦点（模态）、半透明遮罩点击关闭、居中面板卡片 |
| 下拉菜单 | `DropdownBase` / `dropdown()` | 不圈定焦点、面板锚定在 anchor 下方、点击面板不关闭 |
| 轻提示 | `ToastBase` / `toast()` | 不管理焦点、整层点击穿透、到时自动关闭、可注入时间源 |

### Dialog

```kotlin
dialog(
    { dialogOpen.value },           // 打开状态（业务闭包）
    { dialogOpen.value = false },   // 关闭回调（Esc / 点击遮罩）
    width = 400f,
) {
    text({ "确认删除？" })
    button({ "取消" }, { dialogOpen.value = false })
    button({ "删除" }, { delete() }, variant = ButtonVariant.Primary)
}
```

样式可定制：`DialogBase` 上 override `drawScrim`（遮罩）/ `panelWidth` / `panel`（面板容器）/ `contentChildren`（面板内容）。

### Dropdown

```kotlin
dropdown(
    { menuOpen.value },
    { anchorBtn },                  // 锚点节点：面板贴其底部显示
    { menuOpen.value = false },
    width = 160f,
) {
    navItem({ "复制" }, { copy(); menuOpen.value = false })
    navItem({ "删除" }, { del(); menuOpen.value = false })
}
```

样式可定制：`DropdownBase` 上 override `panelWidth` / `offsetY`（面板与锚点底部间距）/ `panel` / `contentChildren`。

### Toast

```kotlin
toast(
    { toastShown.value },           // 是否显示
    { toastShown.value = false },   // 关闭回调（到时自动消失 / 点击内容）
    durationMs = 2000L,
) {
    text({ "已保存" })
}
```

- 显示时**整层不拦截命中**：点击主界面任意位置穿透，只有内容条本身可点（点击立即关闭）；
- 到时自动消失（`durationMs`）；测试可覆盖 `now()` 注入时间源驱动超时；
- 样式可定制：`ToastBase` 上 override `body`（内容条容器）/ `contentChildren`。
