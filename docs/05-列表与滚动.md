# 05 列表与滚动

## 数据列表：renderForEach

在容器的 `argChildren()` 里，用 `renderForEach` 把一组数据渲染成节点，数据变化时节点自动增删、复用：

```kotlin
data class Row(val id: Long, val title: String)

var list by createSignal(listOf(Row(1, "a"), Row(2, "b")))

override fun StateHolderWithNode<Node, List<Node>>.argChildren() {
    renderForEach({ callback ->
        list.forEach { callback(it.id, it) }   // callback(key, value)
    }) { key, it ->
        object : WrappedTextNode(this) {
            override val autoWidth: Boolean get() = true
            override val text: String get() = it.value.title

            override fun onPointerClick(e: PointerEvent) {
                list = list.filter { r -> r.id != key }   // 删除这一行
            }
        }
    }
}
```

- `it.value` 是当前条目，`it.index` 是序号
- 第一个参数（`key`）是**稳定身份**，靠它增删/复用节点，尽量用不可变 id
- 不要手动管理节点，只管数据信号

## 隐藏节点

`hide` 为 true 的节点**不参与布局与命中**（但对象还活着，可恢复）：

```kotlin
var deleted by createSignal(false)

object : WrappedTextNode(this) {
    override val hide: Boolean get() = deleted
}
```

常用于列表行的"暂时收起/删除"（Demo 里的 hide / delete 就是这么做的）。

## 滚动容器

推荐用 `SimpleScrollNode`：一个开箱即用的滚动容器，内部封装了 `Scroll` 注册、`ScrollContent`（裁剪 + 偏移）和滚动条：

```kotlin
object : SimpleScrollNode(this) {
    override val argWidth: LayoutSize get() = LayoutSize(420f, false)
    override val argHeight: LayoutSize get() = LayoutSize(220f, false)
    override val contentGap: Float get() = 6f   // 行间距

    override fun StateHolderWithNode<Node, List<Node>>.contentChildren() {
        renderForEach({ callback -> list.forEach { callback(it.id, it) } }) { key, it ->
            object : RectNode(this), FlexParam {
                override val argHeight: LayoutSize get() = LayoutSize(30f, false)
                // …… 列表行
            }
        }
    }
}
```

要点：

- `SimpleScrollNode(context, direction = Direction.y)`：`direction` 是**滚动方向**（y 纵向 / x 横向），容器布局方向自动取反（内容 + 滚动条排布在垂直方向）
- `contentChildren()`：在这里声明滚动内容
- `contentGap`：内容区行间距；`containerGap`：内容区与滚动条之间的间距
- `argGrow(direction)`：容器在父布局中的增长系数，默认不增长；要占满剩余高度就返回 1f
- `contentDraw(canvas)`：内容区自定义绘制（如边框），在内容子节点绘制前执行
- 滚轮事件已由容器处理（`innerScroll.scroll(e.wheelDelta)`），无需手动 `onPointerWheel`

### 嵌套滚动

同向嵌套时内层先滚，滚到底自动放行给外层：

```kotlin
object : SimpleScrollNode(this) {
    override fun StateHolderWithNode<Node, List<Node>>.contentChildren() {
        object : SimpleScrollNode(this) { /* 内层纵向列表 */ }
        object : SimpleScrollNode(this, Direction.x) { /* 内层横向列表 */ }
    }
}
```

- 内层 `Scroll` 构造时经 `context.consumeScroll(direction)` 向上解析同方向外层 `Scroll` 作为 `parentScroll`；`scroll(delta)` 消费不掉的偏移（`delta - realDelta`）自动转给外层
- 内层横向默认也消费滚轮；如需"仅 Shift+滚轮横向滚动、其余放行给外层"，override `onPointerWheel` 自行判断：

```kotlin
override fun onPointerWheel(e: PointerEvent) {
    if (!engineGlobal.shift) return   // 不消费，事件继续冒泡给外层
    super.onPointerWheel(e)
}
```

### 底层手动模式

`SimpleScrollNode` 等价于下面这套手写组合，低层 API 仍可用，便于自定义：

```kotlin
object : RectNode(this), FlexParam {
    override val layout: LayoutDirection = FlexObject(this)
    override val argWidth: LayoutSize get() = LayoutSize(420f, false)
    override val argHeight: LayoutSize get() = LayoutSize(220f, false)

    val scrollY = Scroll(this).also { registerScroll(it) }

    override fun onPointerWheel(e: PointerEvent) {
        scrollY.scroll(e.wheelDelta)
    }

    override fun StateHolderWithNode<Node, List<Node>>.argChildren() {
        object : ScrollContent(this), FlexParam, GrowChild {
            override val direction: Direction get() = Direction.y
            override val y: Float get() = -scrollY.value
            override fun argGrow(direction: Direction): Float = 1f
            override val layout: LayoutDirection = FlexObject(this)
            // …… 这里放可滚动的行
        }
        object : SimpleScrollBar(this) {
            override val scroll: Scroll get() = scrollY
        }
    }
}
```

- `Scroll(this)`：`this` 是滚动容器。`scrollY.value` 读偏移、`scrollY.scroll(delta)` 滚动、`scrollY.scrollBarSize(direction)` 计算滑块参数
- `registerScroll(it)`：只把 `Scroll` 提供给子树，**不处理滚轮**
- 滚动偏移由 `ScrollContent` 子类**显式 override direction + x/y** 实现；用户可自由自定义：横向用 x、双向同时 override x 和 y、加动画或额外偏移量
- `ScrollContent` 基类只负责裁剪（`drawAtParent` 裁剪 + `acceptClip` 命中限制），超出部分不可见
- 行要**固定宽度/高度**（`LayoutSize(w, false)`）；内容总高由行数决定，超出容器即可滚动

`SimpleScrollBar`（abstract class）：滚动条组件，通过 `object : SimpleScrollBar(this) { override val scroll: Scroll get() = ... }` 使用。默认纵向（轨道宽 10f）；`scroll.direction = Direction.x` 为横向（轨道高 10f）。滑块可拖拽。

## 拖拽

基于指针捕获：在 `onPointerDown` 里调用 `drag(down) { me -> ... }`（`StateHolder` 的扩展，接收者作用域内直接可用），捕获指针后 Move / Up 持续回调（`me.rootX` / `me.rootY` 为窗口级坐标），松手自动解绑：

```kotlin
object : RectNode(this) {
    override fun onPointerDown(e: PointerEvent) {
        drag(e) { me ->
            // me.rootX / me.rootY 是窗口级坐标，配合 absoluteX / absoluteY 换算节点本地
        }
    }
}
```
