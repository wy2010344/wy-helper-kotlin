# 03 文字

所有文字都由 Skia **Paragraph** 排版（同一套文本引擎，跨平台一致，无需自定义测量）。

## 单样式文本：WrappedTextNode

适合一段统一样式的文字，支持自动换行与多行选择：

```kotlin
object : WrappedTextNode(this) {
    override val text: String get() = contentSignal.value
    override val fontFamily: String? = null       // null = 系统字体
    override val fontSize: Float = 16f
    override val fontWeight: Int = 400
    override val italic: Boolean = false          // 斜体
    override val color: ColorInt = rgba(0, 0, 0)
    override val lineHeightMultiplier: Float = 1.4f
    override val letterSpacing: Float = 0f
    override val wordSpacing: Float = 0f
    override val maxLines: Int = Int.MAX_VALUE    // 超行数截断
    override val ellipsis: String = "\u2026"      // 截断处的省略号
    override val textAlign: TextAlign = TextAlign.START
}
```

- **换行宽度**：默认跟随容器内宽。容器 `alignFix = true` + `alignItem = stretch` 时自动拉满；也可显式给 `argWidth` 限制。
- **自适应宽度**：`override val autoWidth = true`，宽度 = 文字实际宽度（适合标题、行内文本）。
- **文字选择**：内置鼠标拖拽多行选择，`selectedText` 返回选中文本、`hasSelection` 判断是否有选区：

```kotlin
object : WrappedTextNode(this) {
    override val text: String get() = longText.value
    override fun onPointerUp(e: PointerEvent) {
        val sel = selectedText
        if (!hasSelection) return
        println("选中了：$sel")
    }
}
```

相邻的文本节点之间还能**跨节点拖选 / 全选 / 复制**（`SelectionManager` 组织成逻辑文档），详见 [06 跨组件文本选择](06-事件与焦点.md)。

## 富文本：RichTextNode

一段文字里混合多种样式，用 `RichTextSpan(text, style)`：

```kotlin
object : RichTextNode(this) {
    override val autoWidth: Boolean get() = true
    override val spans: List<RichTextSpan> get() = listOf(
        RichTextSpan("标题 ", RichTextStyle(fontSize = 22f, fontWeight = 700)),
        RichTextSpan("正文", RichTextStyle(fontSize = 15f, color = rgba(100, 100, 100))),
    )
}
```

`RichTextStyle(fontFamily, fontSize, fontWeight, italic, color, letterSpacing, wordSpacing, lineHeightMultiplier, decoration)`，全部有默认值，按需传参。

**装饰线**：`decoration = TextDecoration.Underline`（下划线）/ `TextDecoration.LineThrough`（删除线），可组合（`TextDecoration(underline = true, lineThrough = true)`）。

**链接**：片段带 `url` 即成为可点击链接，点击经 `UrlOpener.open(url)` 打开（宿主平台注入打开方式，桌面端已内置；也可替换 `UrlOpener.opener` 自定义跳转）：

```kotlin
RichTextSpan("访问官网", style = linkStyle, url = "https://example.com")
```

## 对齐 / 省略号

`TextAlign.START / CENTER / END / JUSTIFY` + `maxLines` + `ellipsis` 对所有文本节点生效：

```kotlin
object : WrappedTextNode(this) {
    override val text: String get() = "很长的文字……"
    override val argWidth: LayoutSize get() = LayoutSize(200f, false)
    override val maxLines: Int get() = 1
    override val textAlign: TextAlign get() = TextAlign.CENTER
}
```

## 输入框：EditableTextNode

继承 `WrappedTextNode`，可编辑、可多行、带光标/选区/撤销：

```kotlin
val editor = object : EditableTextNode(this, maxHistorySize = 100) {
    override val fontSize: Float get() = 15f
}
editor.text = "hello"        // text 可读可写（信号驱动，赋值即重绘）
```

- `text` 是信号属性，程序里读写都走它，赋值即重绘
- 点击聚焦（自动请求系统输入法覆盖层）；**Tab 在多个输入框之间切换焦点**
- 拖拽选择后：Ctrl+C 复制、Ctrl+X 剪切、Ctrl+V 粘贴
- Ctrl+Z 撤销、Ctrl+Y 重做、Ctrl+A 全选；方向键移动，Shift+方向键扩展选区
- **键盘命令**：Home / End 行首尾，Ctrl+Home / Ctrl+End 文档首尾，
  Ctrl+←/→ 词间跳转（Shift 组合扩展词选），Ctrl+Backspace / Ctrl+Delete 删词，
  PageUp / PageDown 垂直翻页移动
- 输入法（IME）组合直接可用；覆写 `onComposing(...)` 可自定义组合处理
- **占位提示**：`placeholder`（空文本时显示）、`placeholderColor`；
  **密码掩码**：`obscureText = true` 把每个字素簇显示为 `•`（选中/复制仍是原文）

程序化编辑（比如配合自绘按钮）：

```kotlin
editor.insertText("x")   // 编辑器节点对象上调用
editor.backspace()
editor.undo()
editor.selectAll()
```

> `undo()` / `redo()` 也可通过 `canUndo` / `canRedo` 控制按钮可用态。

## 富文本编辑器：RichEditableTextNode

继承 `EditableTextNode`，在全部编辑能力之上把内容升级为**样式分段列表**。
打字自动继承插入点左侧样式；删除 / 选区替换 / 撤销重做都会维持样式与文本对齐：

```kotlin
val rich = RichEditableTextNode(this)
rich.text = "hello world"
rich.styleRange(0, 5, RichTextStyle(fontWeight = 700))   // hello 加粗
```

- `styleRange(start, end, style)`：区间设样式；传 `null` 回退到基础样式 `baseStyle`
- 光标导航 / 双击选词等作用于拼接后的全文，与纯文本编辑器一致
- 占位、掩码等父类特性继续可用（掩码逐簇显示圆点且保留各段颜色）
