# 06 事件与焦点

## 指针事件（命中分发）

每次鼠标按下 / 移动 / 抬起，Renderer 做一次**命中测试**，拿到从命中点到根的一整条节点链：

- **捕获阶段（capture）**：从根 → 命中点
- **冒泡阶段（bubble）**：从命中点 → 根

节点按需覆写（统一指针模型，鼠标 / 触摸 / 触控笔归一为 `PointerEvent`）：

```kotlin
object : RectNode(this) {
    override fun onPointerDown(e: PointerEvent) {}
    override fun onPointerUp(e: PointerEvent) {}
    override fun onPointerClick(e: PointerEvent) {}
    override fun onPointerMove(e: PointerEvent) {}
    override fun onPointerWheel(e: PointerEvent) {}
    // 捕获版本：onPointerDownCapture / onPointerUpCapture / onPointerClickCapture / onPointerMoveCapture
}
```

`PointerEvent`：

- `e.x` / `e.y`：节点**本地坐标**
- `e.rootX` / `e.rootY`：窗口级坐标
- `e.wheelDelta`：滚轮增量（Wheel 事件）
- `e.stopPropagation()`：停止继续向父级分发
- 修饰键（Ctrl / Shift 等）**不在事件中携带**，统一读全局信号 `engineGlobal.modifiers`（见下）

命中判定由两个方法决定：

- `acceptHit(x, y)`：这个节点是否算命中（`RectNode` 默认按外包尺寸判定）
- `acceptClip(x, y)`：是否进入该节点的子树继续遍历（被裁剪的容器如 `ScrollContent` 覆写它）

## 全局事件：EngineGlobal

当需要"**命中不到也收得到**"的输入（拖拽移出节点、键盘、输入法）时，在 `init` 里通过 Node 属性 `engineGlobal` 注册回调，并把返回的注销函数放进 `addDestroy`：

```kotlin
init {
    val g = engineGlobal
    val d1 = g.registerKeyPress { e -> /* 键盘：e.key / e.code / e.ctrl / e.shift ... */ }
    val d2 = g.registerComposingText { text, cursor -> /* 输入法组合 */ }
    addDestroy { d1(); d2() }
}
```

- 需要"按住拖出节点仍能持续收到移动"时，在 `onPointerDown` 里调用 `capturePointer`（或用辅助函数 `drag(down) { me -> ... }`），捕获后 Move / Up 只投递给捕获者，`up` 后自动结束；`drag` 辅助函数会把释放动作绑定到宿主 `StateHolder`——宿主销毁（如列表删除行）时自动结束捕获，死节点不会再收到拖拽回调
- 其他可用状态：`g.pointerSelect`（本次指针选择会话：按下 / 释放命中快照）、`g.pressed`（派生：按住中的按下信息）、`g.moveHitTest`（当前命中链）、`g.focused`（当前焦点节点）、`g.ctrl/shift/alt/meta`（真实修饰键状态）、`g.activeEditor`（当前激活 IME 输入框的编辑器，派生自 `focused`）
- 反注册函数务必放进 `addDestroy`，节点销毁时自动清理

## 全局状态信号：engineGlobal

引擎把常用的**输入全局状态**挂在 `engineGlobal` 上，全部是响应式信号，事件处理和绘制层都能按需观察：

```kotlin
val g = engineGlobal
// 事件处理中直接读修饰键
override fun onPointerClick(e: PointerEvent) {
    if (g.ctrl) { /* Ctrl+点击 */ }
}
// 绘制层用 memo 按需依赖：按住 Shift 显示辅助线，其他键变化不重跑
val guideVisible = memo { g.shift }
// 画布工具显示十字准星坐标：命中链头即根容器，其 windowX/Y 是窗口坐标
val pos = memo {
    val h = g.moveHitTest
    if (h != null) "${h.chain.first().windowX.toInt()}, ${h.chain.first().windowY.toInt()}" else "—"
}
```

| 信号 | 含义 | 清空时机 |
|---|---|---|
| `ctrl` / `shift` / `alt` / `meta` | 真实修饰键按键状态（独立可观察） | **只**由键盘事件维护（平台每次按下/释放通过 `updateModifiers` 上报权威快照）；窗口失焦时清空 |
| `pointerSelect` | 本次指针选择会话（`PointerSelect(press, release?)`）：`mouseDown` 写入按下快照，`mouseUp` / 指针离开窗口补填释放快照。`release == null` 即按住中；`release != null` 即定格（悬停不再影响）。Shift+按下时引擎复用上一会话的 `press` 作锚点，实现扩展选择 | 下一次 `mouseDown` 覆盖 |
| `pointerDownHit` | 最近一次指针按下的命中链：每次 Down 写入，Up / 指针离开窗口清空。与 `pointerSelect` 会话**解耦**——双击 / 三击等不开会话的按下同样驱动按压态与点击派发 | Up / 指针离开窗口 |
| `pressed` | **派生属性**：按住中的按下信息（即 `pointerDownHit`）。非空即按住；`pressed.chain.first()` 即根容器（窗口坐标用 `windowX/Y`）、`pressed.include(node)` 判断按在谁身上、`pressed.time` 供点击/长按判定 | 随 `pointerDownHit` 派生 |
| `moveHitTest` | 最近一次指针位置的命中链（`HitestResult.chain.first()` 即根容器，其 `windowX/Y` 是窗口坐标） | 指针离开窗口 |
| 命中设备 | `HitestResult.device`（`PointerDevice.Mouse / Touch / Pen`），由平台在 `mouseDown / mouseMove / mouseUp` 上报并随命中链携带；组件读 `moveHitTest?.device` 判断"触摸 / 笔不产生 hover" | 随事件更新 |
| `focused` | 当前焦点节点 | 焦点变化 |
| `activeEditor` | 当前激活 IME 输入框的编辑器（全局唯一）。**派生属性**：即 `focused as? EditableTextNode`，无独立存储，焦点变化自动更新，绘制层读它即自动跟踪焦点。焦点是原始事实、不随节点销毁清理，活性在消费端校验：`focused` 指向已销毁编辑器时派生为 `null`（键盘派发同样过滤，死编辑器不再收键） | 随 `focused` 与节点活性派生 |

> 指针位置不再单独存 `mouseX/mouseY`：命中链头就是根容器，`hit.chain.first().windowX/Y`（= 根容器绝对坐标 + 局部偏移）即窗口坐标，按需从 `moveHitTest` / `pressed.chain` 读取即可。
> 注意：指针落在**空白区域**时 `moveHitTest.chain` 为空（不是 `null` 也不是长度 ≥1），取 `chain.last()` / `chain.first()` 前应先判空或使用 `lastOrNull()` / `firstOrNull()`。

## 光标

节点覆写 `cursorAt(x, y)` 声明"当前位置应显示什么光标"，引擎把命中链最深层节点的结果交给平台：

```kotlin
// 默认实现：可聚焦元素（如按钮）显示 POINTER，其余 DEFAULT
open fun cursorAt(x: Float, y: Float) =
    if (focusable) CursorType.POINTER else CursorType.DEFAULT

// 文本输入框显示 I 型光标
object : EditableTextNode(this) {
    override fun cursorAt(x: Float, y: Float) = CursorType.TEXT
}
```

`CursorType` 提供 `DEFAULT`（箭头）、`POINTER`（手型）、`TEXT`（文本 I 型）、`CROSSHAIR`（十字准星）、`MOVE`（移动）、`RESIZE_NS / RESIZE_EW / RESIZE_NWSE / RESIZE_NESW`（各向调整大小）、`WAIT`（忙碌）、`HELP`、`NOT_ALLOWED`。平台实现负责映射到系统光标，无法精确映射的类型回退到语义最接近的类型或 `DEFAULT`。

注意：光标在**空白区域**（命中链为空）时统一回退 `DEFAULT`。

注意：修饰键是**纯键盘状态**，只由键盘事件维护，鼠标事件（包括滚轮）不携带也不写入修饰键。它与鼠标按下无关——松鼠标但还按着 Shift 时 `g.shift` 仍为 true；想表达"拖动期间"自己组合 `g.pressed && g.shift`。这也让 **Ctrl+滚轮**、**悬停未按下读修饰键** 都成为可能。

## 键盘与焦点

- 平台把按键转发给 `Renderer.keyPress`；节点通过 `registerKeyPress` 收到 `KeyEvent(key, code, ctrl, shift, alt, meta)`
- **焦点**：`override val focusable = true` 后，节点进入 Tab 遍历；`Tab` 移到下一个、`Shift+Tab` 回上一个（循环）
- 鼠标按下时，Renderer 会把命中目标设为 `focused`；鼠标点在空白处则清空焦点
- **焦点状态是信号**：`EngineGlobal.focused` 存的是当前焦点节点（等价于 `document.activeElement` / Flutter `primaryFocus` / Compose 的 FocusOwner），任何节点在 `draw` / `memo` 里读它都会自动变成响应式——焦点一变，整帧重绘

节点侧无需任何回调钩子，直接读 `isFocused`：

```kotlin
object : RectNode(this) {
    override val focusable: Boolean get() = true

    override fun draw(canvas: PlatformCanvas) {
        if (isFocused) {
            canvas.fillRect(0f, 0f, outerSize(Direction.x), outerSize(Direction.y), rgba(0, 0, 255, 40))
        }
        super.draw(canvas)
    }
}
```

- `isFocused`：当前节点是否持有焦点（`focused === this`）
- `requestFocus()`：程序化请求焦点（等价于 `g.focused = this`，对标 Compose `FocusRequester.requestFocus()` / Flutter `requestFocus()`）

### 遍历顺序

`focusable` 相当于 web 的 `tabindex >= 0`（可被 Tab 拾取，顺序为文档序）。需要**显式顺序**时用 `focusOrder`（相当于 `tabindex` 正数 / Compose `focusOrder` / Flutter `FocusTraversalOrder`）：值越小越先遍历，`null` 排在最后：

```kotlin
object : RectNode(this) {
    override val focusable: Boolean get() = true
    override val focusOrder: Int? get() = 2
}
```

## 跨组件文本选择

文本选择不局限于单个输入框：`SelectionManager` 把所有实现了 `Selectable` 接口的文本节点（`RichTextNode` 系）组织成一份**逻辑文档**，支持跨节点的拖选 / 全选 / 复制：

- **集合即树**：可选节点集合是从渲染树根遍历派生的（纯计算，无命令式注册表）——节点销毁（移出树）或隐藏（`hide`，经 children 过滤）即自动退出选择；按文档序参与；定格端点若指向已消失的节点则该端点作废（指针会话塌缩回锚点或清空），绝不对离树节点做几何换算；
- **可选范围声明（`Node.selectionEnabled`）**：文本可选性不是"实现了 `Selectable` 就必选"，而是子树声明的派生属性（相当于 web 的 `user-select`）。容器声明 `selectionEnabled = false` 时，本节点及整个子树退出可选集合，拖选 / 双击 / 三击 / 全选均不可波及（如 `ButtonBase` 内嵌标签）；遍历派生时对 false 子树直接剪枝，与 `focusTrap` 同为祖先声明、零注册表；
- **拉模型派生**：管理器没有任何 set 选区的入口，"什么地方被选中了"完全由初始原因计算得出——按下位置推导锚点、移动命中推导焦点、Shift 扩展的锚点继承由引擎在按下时复用上一会话的按下快照实现；各节点按需读取自己被分配的范围（`rangeOf`）绘制高亮，无反向推送、无本地副本；
- **拖选**：在任一可选节点上按下拖动即开启选择会话（`pointerSelect`），选区可跨越相邻节点边界；松手时释放快照填入即定格，此后悬停不影响选区；
- **双击选词**：引擎检测到同节点近距快速二次按下时，经段落分词（`Selectable.wordRangeAt`，桌面端为 Skia `getWordBoundary`）物化为编程式选区；编辑器内双击自动分流为其内部词选；
- **双击后拖词扩展**：双击后按住并拖动，选区以原词为锚按词粒度连续扩展（松手或拖出窗口即结束）；
- **三击选段**：同节点第三次按下物化整个逻辑段落（`Selectable.paragraphRangeAt`，以 '\n' 分隔）；
- **点击空白清除**：按下落在可选文本之外时整个选区立即清除（浏览器语义）；
- **外部按下编辑器让位**：按下落在活跃编辑器之外时，引擎先塌缩其本地显式选区（`collapseExternalSelection`，平台惯例）——否则旧的非塌缩选区会在选区派生中遮蔽随后的拖选 / 双击选词结果；
- **全选 Ctrl+A**：从首节点开头到末节点末尾；
- **复制 Ctrl+C**：聚合读取各节点选中片段，按文档序拼接后写入剪贴板（`clipboardSetText`）;
- **剪切 Ctrl+X** 仅对聚焦的编辑器生效（剪切需删除文本，只有编辑器可写）；粘贴仍是编辑器内部行为；
- 编辑器（`EditableTextNode`）只维护自己的本地光标信号（anchor / focus）；聚焦时其光标对在派生链中自动接管（优先级高于定格会话与程序化全选），键盘选区无需任何同步调用即可反映到聚合读取。
- 程序化指令（Ctrl+A / 清除）物化为独立信号，任何指针交互或编辑器光标出现即自动让位；Ctrl+A 物化时会撤除旧指针会话，保证新指令生效。
- **编程式选区**（声明式写入初始原因，非反向同步）：
  - `SelectionManager.select(node, start, end)` 设置单节点内任意区间；`select(anchor, anchorOffset, focus, focusOffset)` 支持跨节点任意端点；
  - 聚焦编辑器时自动路由为其内部选区（写本地光标信号）；目标不可达时返回 `false`；
  - 编辑器侧还有 `moveCursorTo(offset)` 与 `selectRange(start, end)` 直接驱动本地光标；
  - 写入的选区同样处于派生链中：用户拖拽 / 点击编辑器即自然接管，无需失效命令。

```kotlin
// 搜索定位：选中匹配项并高亮
val hit = searchIn(node)
selectionManager.select(node, hit.first, hit.second)
// 聚焦编辑器时光标直达指定位置
editor.moveCursorTo(endOfLine)
```

单编辑器内的光标移动 / 选区扩展行为不变（见 [03](03-文字.md)），跨组件能力是其上的增量层。

## 定时器

跨平台延迟执行，回调派发到主线程（桌面 EDT / Android 主线程 Handler），适合 UI 定时场景（如 Toast 自动关闭）：

```kotlin
// delayMs 后在主线程执行 action，返回取消函数
val cancel: EmptyFun = postDelayed(2000L) { hide() }
addDestroy { cancel() }   // 节点销毁时取消未触发的回调
```

## 键盘快捷键参考

由 `SelectionManager` 统一路由（单编辑器行为由 `EditableTextNode` 内置，见 [03](03-文字.md)）：

| 按键 | 作用 |
|---|---|
| Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z | 撤销 / 重做（匹配对大小写归一：CapsLock 开启或 Shift 参与时平台上报大写字符同样生效） |
| Ctrl+A | 全选（聚焦编辑器内；存在跨节点会话时覆盖整个文档序） |
| Ctrl+C / X / V | 复制 / 剪切 / 粘贴 |
| 方向键 / Shift+方向键 | 移动光标 / 扩展选区 |
| Home / End | 行首 / 行尾 |
| Enter | 换行 |
