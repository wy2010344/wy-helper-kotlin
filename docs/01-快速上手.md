# 01 快速上手

## 这是什么

`skia-engine` 是一个**声明式、信号驱动**的 GUI 引擎：你用普通 Kotlin 对象描述一棵"节点树"，引擎负责布局、绘制与事件分发。没有 XML、没有 Compose。

## 运行 Demo

```bash
./gradlew :desktopApp:run
```

窗口包含：标题、输入框、图片、图形、可滚动列表，覆盖了大部分常用 API。

## 第一个窗口

最小的应用 = 一个 `SkiaApp`（匿名对象）+ 一个 `argChildren()` 描述子节点：

```kotlin
import com.wy.mve.StateHolderWithNode
import org.wy.engine.Node
import org.wy.engine.SkiaApp
import org.wy.engine.WrappedTextNode
import org.wy.engine.layout.FlexObject
import org.wy.engine.layout.FlexParam
import org.wy.engine.layout.LayoutDirection

fun main() {
    object : SkiaApp(800, 600), FlexParam {
        override val layout: LayoutDirection = FlexObject(this)

        override fun StateHolderWithNode<Node, List<Node>>.argChildren() {
            object : WrappedTextNode(this) {
                override val text: String get() = "hello wy-helper"
                override val fontSize: Float get() = 24f
            }
        }
    }
}
```

- `SkiaApp(800, 600)`：窗口初始尺寸；窗口缩放时按实际尺寸重排重绘。
- `FlexParam` + `FlexObject(this)`：让根节点参与 Flex 布局（默认主轴垂直、子节点顺序排列）。
- `argChildren()`：在这里声明子节点。子节点一律用 `object : XxxNode(this) { ... }` 匿名类创建，`this` 就是父容器。

## 两个核心心法

1. **匿名类 + 属性重载**：不传构造参数，一切用 `override val` / `override fun` 配置（见 [02](02-节点与布局.md)）。
2. **信号驱动**：可变状态用 `by createSignal(...)` 声明，赋值即触发相关重绘（见 [02](02-节点与布局.md)）。
