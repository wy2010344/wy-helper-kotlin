# 04 图片与绘制

## 图片节点：ImageNode

```kotlin
val img: PlatformImage? = decodeImage(bytes)   // 解码 PNG/JPEG 等字节

object : ImageNode(this) {
    override val image: PlatformImage get() = img!!             // 图片是动态属性，可重载（如信号驱动、延迟解码）
    override val size: LayoutSizeDirection get() =
        LayoutSizeDirection(Direction.x, 96f, true)             // 指定宽，高按原图比例自动算
    override val radius: Float = 12f                            // 圆角裁剪，0 = 不裁剪
}
```

**尺寸模型**：已知原图宽高比，只用给**一个方向**的尺寸，另一个方向自动按比例算出：

- `size`：唯一的尺寸提示，指定**宽**（`Direction.x`）或**高**（`Direction.y`）之一；`null` 表示不指定（按原图尺寸）
- `LayoutSizeDirection(direction, value, fromInside)` 就是在 `LayoutSize(value, fromInside)` 上多一个方向：

| `fromInside` | 含义 |
|---|---|
| `true` | `value` 是**内容区**尺寸（图片实际绘制区） |
| `false` | `value` 是**外包**尺寸（含 padding），内容区 = value − padding |

**图片永远绘制在 padding 之内的内容区**，`radius` 裁剪内容区圆角：

```kotlin
object : ImageNode(this) {
    override val image: PlatformImage get() = img!!
    override val size: LayoutSizeDirection get() =
        LayoutSizeDirection(Direction.x, 120f, false)   // 外包宽 120
    override fun argPadding(direction: Direction, startEnd: StartEnd) = 12f
    // 内容区 = 96，高度按比例自动算，四周留 12 padding
}
```

- `image` 为 null 时节点无尺寸、不绘制（可配合异步解码/占位）
- `originalWidth` / `originalHeight`：默认取图片像素尺寸，可覆写为其它"固有尺寸"
- `ImageNode` 尺寸**由内部撑开**（内容区 + padding），容器无需 `alignFix` / `stretch`

## 异步图片加载：ImageLoader

`ImageLoader` 是引擎提供的**网络图片薄层**，只管「取字节 → 解码 → 去重缓存」，取字节的网络/线程由宿主注入（引擎不持有平台环境，同 `UrlOpener`）：

```kotlin
val loader = ImageLoader().apply {
    fetcher = { url, onBytes ->                          // 平台注入：后台线程取字节再回传
        thread { onBytes(URL(url).readBytes()) }
    }
}

loader.load("https://x/a.png") { image ->                // 成功后 image 为解码结果
    imageSignal.set(image)                               // 驱动 ImageNode.image 刷新
}
```

语义保证：

- **同 URL 去重**：多个调用并发加载同一 URL，只 fetch 一次，结果共享
- **结果缓存**：解码成功进内存缓存，后续直接回调缓存值，不再取字节
- **失败重试**：解码失败/取字节失败回调 `null`，不缓存，下次加载重新取
- 未注入 `fetcher` 时直接回调 `null`（不崩溃）

注意：`fetcher` 必须恰好回调一次 `onBytes`；跨线程时需要由实现方自行把结果切回主线程（本层不做线程切换）。

任何节点覆写 `draw(canvas)` 就能自绘，坐标系是**节点本地坐标**（`(0,0)` 为节点左上角）：

```kotlin
object : RectNode(this) {
    override val argWidth: LayoutSize get() = LayoutSize(120f, false)
    override val argHeight: LayoutSize get() = LayoutSize(80f, false)

    override fun draw(canvas: PlatformCanvas) {
        canvas.fillRoundRect(0f, 0f, 120f, 80f, 16f, rgba(220, 240, 220))
        canvas.strokeRoundRect(0f, 0f, 120f, 80f, 16f, rgba(0, 150, 0), 2f)
        super.draw(canvas)   // 别忘了继续画子节点
    }
}
```

| 方法 | 作用 |
|---|---|
| `clear(color)` | 清屏 |
| `fillRect(x, y, w, h, color[, gradient])` / `strokeRect(...)` | 矩形填充 / 描边 |
| `fillRoundRect(x, y, w, h, radius, color[, gradient])` / `strokeRoundRect(...)` | 圆角矩形 |
| `fillOval(x, y, w, h, color[, gradient])` / `strokeOval(...)` | 椭圆（w == h 即圆） |
| `drawLine(x1, y1, x2, y2, color, strokeWidth)` | 线段 |
| `fillPath(path, color[, gradient])` / `strokePath(path, color, strokeWidth[, dash, phase])` | 路径填充 / 描边（贝塞尔曲线、虚线） |
| `drawShadow(x, y, w, h, radius, blurSigma, color)` | 圆角矩形软阴影 |
| `drawImage(image, x, y, w, h)` | 位图（通常直接用 `ImageNode`） |
| `drawParagraph(p, x, y)` | 段落（通常直接用文字节点） |
| `save()` / `restore()` | 保存 / 恢复画布状态 |
| `translate(dx, dy)` / `rotate(deg)` / `scale(sx, sy)` | 变换 |
| `saveLayerAlpha(alpha)` | 开启透明度层（必须配一次 `restore`） |
| `clipRect(x, y, w, h)` / `clipRRect(...)` | 裁剪 |

颜色：`rgba(r, g, b, a = 255)`，返回 `ColorInt`（`Int`）。

## 路径 Path 与贝塞尔曲线

`Path` 用命令式构建（`moveTo` / `lineTo` / `quadTo` / `cubicTo` / `close`），既可用于**绘制**也可用于**命中检测**（`contains`，翻译为平台原生 Path 后做精确判定）：

```kotlin
val heart = Path()
    .moveTo(60f, 100f)
    .cubicTo(10f, 60f, 30f, 20f, 60f, 40f)   // 左心瓣
    .cubicTo(90f, 20f, 110f, 60f, 60f, 100f)  // 右心瓣
    .close()

object : RectNode(this) {
    override val argWidth get() = LayoutSize(120f, false)
    override val argHeight get() = LayoutSize(120f, false)
    override fun draw(canvas: PlatformCanvas) {
        canvas.fillPath(heart, rgba(220, 60, 60))
        super.draw(canvas)
    }
    // Path 本身也能做命中：if (heart.contains(localX, localY))
}
```

## 线性渐变

`fillRect` / `fillRoundRect` / `fillOval` / `fillPath` 都接受可选的 `gradient` 参数（类型为 `Gradient`），设置渐变后忽略 `color`。支持**线性**、**径向**与**扫描**三种：

```kotlin
// 线性渐变
val sunset = LinearGradient(
    startX = 0f, startY = 0f,
    endX = 120f, endY = 80f,
    colors = listOf(rgba(255, 140, 60), rgba(255, 60, 120)),
    stops = null,  // null = 颜色均匀分布；也可传与 colors 等长的 0..1 位置列表
)
canvas.fillRoundRect(0f, 0f, 120f, 80f, 16f, gradient = sunset)

// 径向渐变：从圆心向外扩散，圆外区域以最后一个颜色延伸
val sun = RadialGradient(
    centerX = 60f, centerY = 40f, radius = 50f,
    colors = listOf(rgba(255, 240, 120), rgba(255, 90, 30)),
)
canvas.fillOval(10f, 10f, 100f, 60f, gradient = sun)

// 扫描渐变：绕圆心（正 x 轴方向 0° 起）顺时针一圈，首尾颜色在 360° 处相接
val dial = SweepGradient(
    centerX = 60f, centerY = 60f,
    colors = listOf(rgba(255, 60, 60), rgba(60, 200, 60), rgba(60, 60, 255)),
)
canvas.fillOval(20f, 20f, 80f, 80f, gradient = dial)
```

## 虚线描边

`strokePath` 支持虚线：`dash` 为 `[实线长, 空白长, ...]`（可多组），`phase` 为起始偏移：

```kotlin
val dashLine = Path().moveTo(0f, 20f).lineTo(200f, 20f)
canvas.strokePath(dashLine, rgba(150, 150, 150), strokeWidth = 2f, dash = floatArrayOf(6f, 4f))
```

## 软阴影

`drawShadow` 给圆角矩形画一道模糊阴影（实时 saveLayer + blur 合成），颜色建议带透明度：

```kotlin
override fun draw(canvas: PlatformCanvas) {
    canvas.drawShadow(0f, 0f, 120f, 80f, 16f, 8f, rgba(0, 0, 0, 60))
    fillOuterRoundRect(canvas, 16f, CARD)
    super.draw(canvas)
}
```

`LayoutNode` 有几个便利方法，直接画出自己的外包/内容矩形，不用手写坐标：

| 方法 | 效果 |
|---|---|
| `fillOuterRect(canvas, color)` / `fillInnerRect(canvas, color)` | 填充外包 / 内容矩形 |
| `strokeOuterRect(canvas, color, strokeWidth)` / `strokeInnerRect(...)` | 描边外包 / 内容矩形 |
| `fillOuterRoundRect(canvas, radius, color)` / `fillInnerRoundRect(...)` | 圆角矩形填充 |
| `strokeOuterRoundRect(canvas, radius, color, strokeWidth)` / `strokeInnerRoundRect(...)` | 圆角矩形描边 |
| `fillOuterOval(canvas, color)` / `fillInnerOval(canvas, color)` | 椭圆填充 |
| `strokeOuterOval(canvas, color, strokeWidth)` / `strokeInnerOval(...)` | 椭圆描边 |
| `strokeOuterRing(canvas, gap, radius, color, strokeWidth)` | 沿外缘一圈描边；`gap` 为离外缘的间距（负值向内缩），画焦点环常用 `strokeOuterRing(canvas, 2f, 10f, ACCENT, 2f)` |

用法（`draw(canvas)` 里，接收者即节点自己）：

```kotlin
override fun draw(canvas: PlatformCanvas) {
    fillOuterRoundRect(canvas, 8f, CARD)          // 背景
    strokeOuterRoundRect(canvas, 8f, BORDER, 1f)  // 边框
    if (isFocused) strokeOuterRing(canvas, 2f, 10f, ACCENT, 2f)  // 焦点环
    super.draw(canvas)
}
```

## 透明度与变换

节点没有内置的透明度/变换属性，一切在 `draw` 里手动控制（更灵活）。`saveLayerAlpha` 开启透明度层后，后续绘制（含 `super.draw` 的子节点）都按该透明度合成：

```kotlin
override fun draw(canvas: PlatformCanvas) {
    canvas.saveLayerAlpha(0.4f)      // 本节点及其子树按 40% 透明度合成
    super.draw(canvas)
    canvas.restore()                 // 必须配对一次 restore
}
```

变换同理，用 `save → translate/rotate/scale → ... → restore`：

```kotlin
override fun draw(canvas: PlatformCanvas) {
    canvas.save()
    canvas.translate(60f, 40f)
    canvas.rotate(30f)
    canvas.translate(-60f, -40f)   // 绕着节点中心转
    canvas.fillRect(20f, 20f, 80f, 40f, rgba(120, 0, 200))
    canvas.restore()
    super.draw(canvas)
}
```
