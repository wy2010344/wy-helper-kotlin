# 09 - 动画信号

包:`org.wy.engine.animation`(skia-engine/commonMain,平台 actual:jvmMain / androidMain)

把"值随时间平滑变化"表达为响应式信号:每帧写入值 → Signal 监听器触发
`Renderer.frameCallback` → 自动重绘,**引擎零侵入**。设计移植自参考实现
`animateSignal.ts`,采用函数式动画——每帧由 diffTime 纯计算位移,可随时打断、无状态漂移。

## 一、帧源(FrameSource)

```kotlin
fun interface FrameSource {
    fun subscribe(callback: (diffTimeMs: Float) -> Boolean,
                  onFinish: (success: Boolean) -> Unit): FrameSubscription
}
interface FrameSubscription { fun cancel() }
expect val DefaultFrameSource: FrameSource
```

契约:

- callback 仅以 `diffTime > 0` 调用(自订阅时刻起的毫秒数),且不会在
  subscribe 调用栈内同步触发——订阅方可先登记再订阅;
- 返回 true = 自然结束 → `onFinish(true)`;cancel = 外部取消 → `onFinish(false)`;onFinish 至多一次。

平台实现只需提供两个原语(commonMain 的 `loopFrameSource` 统一处理循环逻辑):

| 原语 | Desktop | Android |
|---|---|---|
| 时钟 | `System.nanoTime` | `SystemClock.uptimeMillis` |
| 帧调度 | 单线程调度器 16ms 节拍 → `invokeLater` 切回 EDT | Choreographer vsync |

## 二、AnimateSignal

```kotlin
class AnimateSignal(initValue: Float, frames: FrameSource = DefaultFrameSource)
class AnimateSignal(ref: OneSetStoreRef<Float>)          // 绑定已有信号

val value: Float        // 当前值;在渲染/memo 中读取即建立响应式依赖
val onAnimation: Boolean // 是否有动画进行中(响应式)
fun getTarget(): Float   // 动画中为配置目标(含 silentDiff 推进),否则当前值
```

方法一览(TS 对应):

| 方法 | 语义 |
|---|---|
| `set(n)` | 直接写值并打断动画。帧回调内调用会抛异常(lock) |
| `stop()` | 冻结在当前值(打断但不改值) |
| `changeDiff(n)` | 增量写值并打断动画 |
| `silentDiff(n)` | **外部增量**:动画中平移基准与目标(不打断时钟);空闲时直接加值 |
| `silentChangeTo(n)` | 改写目标不重启动画;空闲时直接写值 |
| `change(config)` | 启动自定义动画,返回 `Deferred<Boolean>` |
| `animateTo(n, config = defaultSpringAnimationConfig)` | 动画到目标值;零位移立即完成 |
| `changeTo(n, config?)` | 有配置则动画,否则直接写值 |

Deferred 结果:`true` = 自然完成或无事可做,`false` = 被打断(set/stop/新动画均可打断)。
不关心结果可忽略返回值;需要时 `runBlocking { } / coroutineScope { }` 中 `await()`。

### 典型用法

```kotlin
val progress = AnimateSignal(0f)

// 弹簧到 1f(默认临界阻尼 ω0=20)
progress.animateTo(1f)

// 滚动惯性:silentDiff 接手指增量,抬起后带初速度弹簧归位
scroll.silentDiff(delta)
scroll.animateTo(target, spring(SpringAnimationArg(initialVelocity = velocity)))
```

### 锁规则

帧回调执行期间、以及配置工厂构造期间,信号处于锁定状态:
此时调用 `set`/`change` 会抛 `IllegalStateException("禁止在此时修改")`,
防止动画回调内改值造成重入。

## 三、SilentDiff 与自定义动画配置

```kotlin
fun interface AnimateSignalConfig {
    fun create(out: SilentDiff): ((diffTimeMs: Float) -> Boolean)?   // null=立即完成
}

class SilentDiff(...) {
    val getCurrent: () -> Float
    var target: Float?
    fun setDisplayment(n: Float)   // 输出动画位移(相对基准 initValue)
    fun silentDiff(n: Float)       // 基准+当前值+目标同步平移
    fun silentChangeTo(n: Float)
}
```

`SilentDiff` 在 change 开始时快照 `initValue`;动画帧只负责输出位移量;
外部输入通过 silent* 平移基准与目标,与动画输出互不干扰——这是滚动类场景的核心机制。

便捷构造器:

```kotlin
// 位移式:直接给位移量,返回 true 结束
fun animationTime(frame: (diffTimeMs: Float, setDisplacement: (Float) -> Unit) -> Boolean): AnimateSignalConfig
typealias DeltaXAnimateConfig = (deltaX: Float) -> AnimateSignalConfig
```

## 四、内置动画:tween / spring

### tween(时长缓动)

```kotlin
fun tween(durationMs: Float, fn: EaseFn = EaseFns.linear): DeltaXAnimateConfig
```

进度 `pc>=1` 时精确落在目标值并自然结束。

缓动函数集 `EaseFns`:`linear` / `poly(n)` / `quad`…`quint` / `sine` / `expo` /
`circ` / `back(s)` / `bounceOut` / `elasticOut(bounciness)` / `elastic(a,p)`;
包装器 `easeOutFn(easeIn)` / `easeInOutFn` / `easeOutInFn` 可由 in 曲线派生其余形态。

### spring(物理弹簧)

```kotlin
data class SpringBaseArg(val omega0: Float = 20f, val zta: Float = 1f)
data class SpringAnimationArg(
    val config: SpringBaseArg = SpringBaseArg(),   // 物理参数
    val initialVelocity: Float = 0f,               // px/ms,手势抬起速度
    val displacementThreshold: Float = 0.5f,       // 停止距离阈值(px)
    val velocityThreshold: Float = 10f,            // 停止速度阈值(px/s)
)
fun spring(arg: SpringAnimationArg = SpringAnimationArg()): DeltaXAnimateConfig

// k-d-m 换算:ω0=√(k/m)、ζ=d/(2√(km))
fun getZtaAndOmega0From(stiffness: Float, damping: Float, mass: Float): SpringBaseArg

// 停止判定:剩余距离与速度同时小于阈值
fun springIsStop(n: SpringOutValue, displacementThreshold: Float = 0.5f, velocityThreshold: Float = 10f): Boolean
```

物理为解析解三分支:ζ<1 欠阻尼(衰减振荡)、ζ=1 临界阻尼、ζ>1 过阻尼。
停止判定命中时**精确落在目标值**(snap)。默认临界阻尼 ω0=20,
阈值参考 Framer Motion(0.5px 在像素域几乎无法察觉)。
